# Lesson 004 — Custom Text Selection

An interactive beginner-friendly lesson about styling selected text with CSS `::selection`.

## Learning Objectives

- Understand the `::selection` pseudo-element.
- Customize selected text with `color`.
- Change the selection background using `background-color`.
- Use CSS custom properties to switch color palettes.
- Choose readable foreground and background combinations.
- Experiment with selection colors in a live preview.

## Features

- Editorial cream, plum, and coral design
- Four selectable color palettes
- Live selection-color changes
- Dynamic CSS example
- Copy CSS button
- Responsive layout
- Keyboard-accessible palette controls
- Reduced-motion support
- Vanilla HTML, CSS, and JavaScript

## Files

- `index.html` — lesson content and interactive preview
- `style.css` — styling, palettes, and responsive layout
- `script.js` — palette switching and CSS copying

## Run Locally

Open `index.html` in a modern browser. For clipboard functionality, use localhost or an HTTPS deployment.
